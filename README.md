# Redianice

Site web de Redianice.

## Configuration locale

Copiez les variables de `.env.example` dans `.env`, puis renseignez les valeurs nécessaires. Ne partagez jamais `.env` : il est exclu de Git. Sur Vercel, configurez ces variables dans les paramètres du projet.

Variables utilisées par l’API de contact : `RESEND_API_KEY`, `RESEND_FROM` et `CONTACT_TO`.
